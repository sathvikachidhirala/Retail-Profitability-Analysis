# Python Scripts

This folder contains Python scripts used in the Retail Profitability Analysis project.

## Tools Used
- Python
- Pandas
- MySQL Connector

## Scripts
- `data_inspection.py` – Data inspection
- `business_analysis.py` – Business analysis
- `profitability_analysis.py` – Profitability analysis
- `discount_analysis.py` – Discount analysis
- `regional_analysis.py` – Regional analysis
- `mysql_import.py` – Importing data into MySQL
