# Retail Profitability Analysis

## Project Overview
This project analyzes retail sales and profitability using Python, MySQL, and Power BI.

## Tools Used
- Python
- Pandas
- MySQL
- Power BI

## Project Components
- Python scripts for data cleaning and analysis
- SQL queries for business analysis
- Interactive Power BI dashboard
- Business Insights and Recommendations report

## Key Findings
- Technology generated the highest profit among product categories.
- Tables, Bookcases, and Supplies recorded negative profits.
- The West region generated the highest profit.
- The analysis explored discount levels and profitability.

## Objective
To identify profitability trends and support data-driven business decisions.

## Dataset
Sample Superstore dataset used for educational and portfolio purposes.
